# Rios Principales y de Cuencas Transfronterizas del Peru

Caracteristicas hidrogaficas de los principales rios y sistemas hidricos
compartidos en fronteras.

## Usage

``` r
rios_frontera
```

## Format

Un data frame con nombre del rio, vertiente hidrografica, longitud y
cuenca.

## Source

Autoridad Nacional del Agua (ANA) / INEI.
