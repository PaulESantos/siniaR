# Areas de Conservacion Regional (ACR) reconocidas por SERNANP

Informacion sobre las Areas de Conservacion Regional (ACR) establecidas
en el Peru para la proteccion de ecosistemas y biodiversidad a nivel
subnacional.

## Usage

``` r
acr_sernanp
```

## Format

Un data frame con variables de ubicacion, nombre del ACR, base legal y
superficie en hectareas.

## Source

Servicio Nacional de Areas Naturales Protegidas por el Estado (SERNANP)
/ INEI.
