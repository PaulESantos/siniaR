# Especies de Flora y Fauna Amenazadas (2013-2020)

Registro historico del numero de especies de flora y fauna silvestre
amenazadas segun categorias de conservacion (Vulnerable, En Peligro, En
Peligro Critico).

## Usage

``` r
flora_fauna_2013_2020
```

## Format

Un data frame con registros anuales por grupo taxonomico y categoria de
amenaza.

## Source

SERFOR / Ministerio del Ambiente (MINAM) / INEI.
