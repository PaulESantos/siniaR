# Temperatura Maxima Promedio Anual segun Departamento

Serie historica de temperatura maxima promedio anual (grados Celsius,
°C) registrada por departamento.

## Usage

``` r
temperatura_maxima
```

## Format

Un data frame con departamento y serie de temperaturas maximas anuales
(°C).

## Source

Servicio Nacional de Meteorologia e Hidrologia del Peru (SENAMHI) /
INEI.
