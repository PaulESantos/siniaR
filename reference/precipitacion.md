# Precipitacion Total Anual segun Departamento

Serie historica de precipitacion total anual acumulada (milimetros, mm)
registrada en las principales estaciones meteorologicas por
departamento.

## Usage

``` r
precipitacion
```

## Format

Un data frame con departamentos y valores anuales de precipitacion en
mm.

## Source

Servicio Nacional de Meteorologia e Hidrologia del Peru (SENAMHI) /
INEI.
