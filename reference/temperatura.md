# Temperatura del Aire Promedio Anual segun Departamento

Serie historica de temperatura media anual del aire (grados Celsius, °C)
registrada en estaciones meteorologicas de capitales departamentales.

## Usage

``` r
temperatura
```

## Format

Un data frame con departamento y serie de temperaturas promedio anuales
(°C).

## Source

Servicio Nacional de Meteorologia e Hidrologia del Peru (SENAMHI) /
INEI.
