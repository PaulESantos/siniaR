# Areas de Conservacion Privada (ACP) reconocidas por SERNANP

Conjunto de datos con el registro de las Areas de Conservacion Privada
(ACP) en el territorio peruano, reconocidas mediante resolucion
ministerial.

## Usage

``` r
acp_sernanp
```

## Format

Un data frame (`tbl_df`) con informacion de:

- departamento:

  Nombre del departamento donde se ubica el area.

- area_de_conservacion:

  Nombre oficial del Area de Conservacion Privada.

- base_legal:

  Norma legal de reconocimiento o establecimiento.

- sup_ha:

  Superficie total del area en hectareas (ha).

- fecha_promulgacion:

  Fecha oficial de promulgacion o reconocimiento.

## Source

Servicio Nacional de Areas Naturales Protegidas por el Estado (SERNANP)
/ INEI.
