# Catalogo de Enlaces a Archivos Excel Tematicos del INEI

Tabla de referencia con los titulos tematicos y enlaces directos de
descarga a las tablas estadisticas del anuario ambiental del INEI.

## Usage

``` r
xlsx_links
```

## Format

Un data frame con titulo de la tabla y URL de descarga oficial en
formato `.xlsx`.

## Source

Instituto Nacional de Estadistica e Informatica (INEI).
