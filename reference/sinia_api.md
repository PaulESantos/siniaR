# Interfaz para Estadísticas Ambientales del SINIA / MINAM

Funciones para listar indicadores, buscar, consultar fichas técnicas y
descargar conjuntos de datos del Sistema Nacional de Información
Ambiental (SINIA).

El Sistema Nacional de Información Ambiental (SINIA) es un sistema
funcional del Sistema Nacional de Gestión Ambiental (SNGA), que
comprende un conjunto de principios, normas, procedimientos, técnicas e
instrumentos a fin de facilitar el acceso y uso de la información
ambiental que las entidades que lo conforman generan o poseen, en el
ámbito de sus respectivas competencias.
